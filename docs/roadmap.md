# Roadmap

Execution checklist for Everyday Tools. Status is updated as milestones land.

## Milestone 1 — Foundation

- [x] Inspect the environment, Git state, and GitHub authentication
- [x] Initialize Next.js, TypeScript, Tailwind, pnpm, Vitest, and Playwright
- [x] Add product documentation, license, and security guidance
- [x] Add GitHub Actions
- [ ] Create the GitHub repository and push the foundation

## Milestone 2 — Design system and navigation

- [ ] Theme, typography, and shared controls
- [ ] Desktop shell, collapsible sidebar, and mobile navigation
- [ ] Typed tool registry
- [ ] Global search and command palette (`Ctrl/Cmd + K`)
- [ ] Stable tool routes and tool-page layout

## Milestone 3 — Essential developer tools

- [ ] Random secrets, passwords, passphrases, UUIDs, and API keys
- [ ] Encoding and decoding utilities
- [ ] JSON formatter, validator, tree, and diff
- [ ] Text counters, case conversion, and text diff
- [ ] Timestamp converter
- [ ] Unit converter
- [ ] QR code generator

## Milestone 4 — Color Studio

- [ ] Shared color engine and live conversion
- [ ] Palette, gradient, contrast, and CSS variable tools

## Milestone 5 — Image workspace

- [ ] Upload, compress, resize, convert, crop, rotate, and flip
- [ ] Dimensions, metadata removal, color extraction, and data URLs

## Milestone 6 — Structured data and development helpers

- [ ] YAML, CSV, XML, TOML, env diff, and JSON Schema
- [ ] SQL and code formatting, regex, cron, JWT, and hash tools
- [ ] URL, cURL, and configuration generators

## Milestone 7 — Documents and remaining utilities

- [ ] PDF merge, split, rotate, extract, watermark, and metadata
- [ ] Date math, percentages, web references, and small generators

## Milestone 8 — Production readiness

- [ ] Keyboard and responsive checks
- [ ] Privacy check: local tools do not send input over the network
- [ ] Lint, typecheck, unit tests, production build, and Playwright
- [ ] Tool inventory matches shipped behavior
