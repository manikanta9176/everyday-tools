# Roadmap

Execution checklist for Everyday Tools. Status is updated as milestones land.

## Milestone 1 — Foundation

- [x] Inspect the environment, Git state, and GitHub authentication
- [x] Initialize Next.js, TypeScript, Tailwind, pnpm, Vitest, and Playwright
- [x] Add product documentation, license, and security guidance
- [x] Add GitHub Actions
- [x] Create the GitHub repository and push the foundation

## Milestone 2 — Design system and navigation

- [x] Theme, typography, and shared controls
- [x] Desktop shell, collapsible sidebar, and mobile navigation
- [x] Typed tool registry
- [x] Global search and command palette (`Ctrl/Cmd + K`)
- [x] Stable tool routes and tool-page layout

## Milestone 3 — Essential developer tools

- [x] Random secrets, passwords, passphrases, UUIDs, and API keys
- [x] Encoding and decoding utilities
- [x] JSON formatter, validator, tree, and diff
- [x] Text counters, case conversion, and text diff
- [x] Timestamp converter
- [x] Unit converter
- [x] QR code generator

## Milestone 4 — Color Studio

- [x] Shared color engine and live conversion
- [x] Palette, gradient, contrast, and CSS variable tools

## Milestone 5 — Image workspace

- [x] Upload, compress, resize, convert, crop, rotate, and flip
- [x] Dimensions, metadata removal, color extraction, and data URLs

## Milestone 6 — Structured data and development helpers

- [x] YAML, CSV, XML, TOML, env diff, and JSON Schema
- [x] SQL and code formatting, regex, cron, JWT, and hash tools
- [x] URL, cURL, and configuration generators

## Milestone 7 — Documents and remaining utilities

- [x] PDF merge, split, rotate, extract, watermark, and metadata
- [x] Date math, percentages, web references, and small generators

## Milestone 8 — Production readiness

- [x] Keyboard and responsive checks
- [x] Privacy check: local tools do not send input over the network
- [x] Lint, typecheck, unit tests, production build, and Playwright
- [x] Tool inventory matches shipped behavior

Not shipped: barcode generation, an HTTP request tester, DNS lookup, PDF text extraction, PDF compression, and a service worker. See the inventory.
